# Dan Michael Villamarin — Portfolio

## Setup
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
1. Push to GitHub
2. Import repo in Vercel
3. Framework: Vite
4. Build command: `npm run build`
5. Output directory: `dist`

## Video Background
Drop your background video as `public/bg-video.mp4`
It will auto-play muted and looped behind the hero.

## Swap screenshots
When you have real project screenshots, replace the mock thumbs in the WorkTable component.
